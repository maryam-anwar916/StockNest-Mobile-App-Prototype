# 📈 Stock Nest

**Stock Nest** is a sleek, modern mobile app designed to simplify and enhance the stock investing experience. Whether you're new to investing or looking to streamline your portfolio tracking, Stock Nest offers the tools to help you make smarter financial decisions.

---

## 🚀 Features

- **User Authentication**: Secure email-based login.
- **Watchlist Management**: Track favorite stocks like Apple and Tesla.
- **Real-Time Market Overview**: See top gainers and losers at a glance.
- **Stock Detail Page**: Live pricing, performance charts, and key statistics.
- **News Integration**: Stay updated with the latest market headlines.
- **Portfolio Dashboard**: Visualize portfolio performance and holding summaries.
- **Pro Version**:
  - Real-time price data
  - Advanced analytics
  - Custom alerts
  - Ad-free experience
- **Explore by Categories**: Browse stocks by sectors like Technology, Healthcare, Energy, and Financials.
